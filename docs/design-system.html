Dark Mode Reference

Dark Mode Surfaces

Dark mode uses --bg-dark (#1A1A1A) as page, --bg-dark-surface (#262626) for cards/panels, --bg-dark-input (#333) for inputs and interactive surfaces. Borders are rgba(255,255,255,0.1). Text is white/rgba(255,255,255,0.6)/(0.4).
